# Frontend

This folder contains the React + Vite frontend for the Matcha Shop demo.

## Getting started

```bash
cd frontend
npm install
npm run dev
```

## Running the app
Open the URL printed by Vite, usually `http://localhost:5173`.

## Notes
- Admin login is available through the login modal.
- Checkout now submits orders to the backend API.
- If the backend is offline, the app falls back to demo seed products.
